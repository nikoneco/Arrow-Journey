# Arrow Journey

曲がった矢印を順番に抜いていくパズルPWA。Vanilla JavaScript / SVG / IndexedDB、Viteで配布用ファイルを生成する。

## 起動

Node.js 22.12以降を使用する。

```sh
npm ci
npm run dev
```

本番ビルドとオフライン動作の確認:

```sh
npm run build
npm run preview
```

プレビューは `http://127.0.0.1:4173/`。Service Workerは本番ビルドだけに登録する。

## 機能

- Easy / Normal / Hard / Expertの各難易度で28/32/36/40角を生成。大きさと難易度を分離し、抜ける候補数・選択肢の推移・依存深さで調整。Expertでは長い曲線を保ちながら短い端切れと解放の集中を抑える。難易度の行を押すと新規開始。
- 正方形・円・ひし形・十字・ハート・ドーナツ。ランダムは正方形80%、ほかの5形状は各4%。手動選択もでき、サイズ・難易度から独立。長さ2〜30の片端矢印が形の内側を100%占有し、形の外に矢印やドットを置かない。シード再現、構造検証、独立解法とDAGで全消去確認。
- 先端の直線上に残存矢印がなければ除去。穴を挟んだ向こう側も判定する。胴体は元の経路に沿って移動。
- ミスによる終了・時間制限なし。ミス数は既定で非表示、設定でプレイ中とクリア時の表示を切り替え。成績にノーミス項目を表示しない。ヒントは1盤面3回。同じ盤面状態の再表示は追加消費しない。
- 矢印のマスを450ms長押しすると、先端から外枠まで中立な直線ガイドを表示。指を離しても除去しない。ドラッグ・ピンチ・画面切替で解除。
- 消去済みマスの中心に薄いドット。PC盤面のカーソルは人差し指で統一。ドラッグ・ピンチ・ホイール・ズームボタン。ドラッグや空白タップはミスに数えない。
- 携帯では残り本数・拡大縮小・全体表示・ヒントを盤面上部の1段にまとめ、画面の残りの高さを表示枠に使う。盤面とマスは正方形のまま、拡大時に上下の広い範囲を操作できる。ノッチ等の余白と画面回転に対応。
- 途中盤面は端末内のみ。新規開始で置換。成績・設定と原子的に保存し、古いタブからの上書きを拒否。
- 4色の矢印、ライト/ダーク/端末連動、角丸の経路、移動演出・保存中の連続操作。BGM・効果音の個別ON/OFFと音量、動きを減らす設定。5曲のゆっくりしたオリジナル合成BGMを盤面ごとに選曲し、再開時も同じ曲を使用。効果音も現在の曲の和音に合わせ、連続操作時の音量と同時発音数を抑える。録音・音源配信への依存なし。
- 盤面の連続タップによるブラウザー拡大を抑止。ゲーム内のピンチ・ドラッグ・ズームボタンを維持。
- オフラインで新規生成・再開。更新待機中は「更新」ボタンを表示し、保存後に切替。

## 検証

```sh
npm test
# 別ターミナルで npm run preview を起動してから:
npm run test:e2e
```

自動ブラウザー検証はインストール済みGoogle Chromeを使用する。Nodeの通常テストには正方形の各難易度×6サイズ×100シード・計2400盤面と、6形状×6サイズ×4難易度×25シード・計3600盤面の全消去検証、ランダム形状の選択率、Expertの追加シード検証を含む。Firestore Emulatorによるルール試験は通常は明示的にskipする。実行方法は [INTEGRATION.md](docs/INTEGRATION.md) を参照。

## クラウドと公開の状態

0.6.1。公開先: [Arrow Journey PWA](https://nikoneco.github.io/Arrow-Journey/)。携帯の操作を上部へ集約し、拡大時に使える表示枠を縦長にした。生成器5.0.0の6形状・28〜40角と難易度調整を維持する。保存中の盤面は生成し直さず再開する。矢印が占有する各マスの全体でタップを受け付け、線から離れた端や角も選択できる。公開・認証・同期の確認記録は [INTEGRATION.md](docs/INTEGRATION.md) に記載する。iPhone/Android実機の確認は別途必要。

- Arrow Journey専用FirebaseをSparkプランで作成。Google認証・本人UID別のFirestoreルールを設定。途中盤面は送信しない。
- `gas/` は公開読取API。実Sheetの4難易度metadataを匿名配信し、接続失敗時は同梱値を使う。ゲーム開始にGAS接続を要求しない。
- `nikoneco/Arrow-Journey` のGitHub Pages。manifestのIDは `/Arrow-Journey/`。数独の `/Sudoku/` と既存ルートIDは変更しない。
- `.github/workflows/pages.yml` はmainへのpushまたは手動実行で `dist/` を公開する。現在の依頼で新規公開まで承認済み。
- 管理ID、認証情報、接続先の完全仕様書は公開ソースへ追加しない。

仕様と実装判断: [IMPLEMENTATION.md](docs/IMPLEMENTATION.md)。外部接続と保存契約: [INTEGRATION.md](docs/INTEGRATION.md)。
