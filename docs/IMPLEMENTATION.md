# 実装判断と受入条件

2026-10-22 / 0.5.0

元仕様の「文書作成のみ」は過去の作業範囲。今回はゲームの作成依頼として実装。管理URLを含む元仕様書は公開ツリーに複製しない。

## 現在のUI要件

ユーザーの最新訂正を優先する。

1. 均等な格子の形状mask内を隙間なく埋める。正方形・円・ひし形・十字・ハート・ドーナツ、形の外と穴は空白。矢印の先端は片端に1つだけ。
2. 数独のホーム構成を参照。難易度行で新規開始、「つづきから」、設定・成績・遊び方。キャッチコピーや情緒的な文言は不要。
3. Service Worker更新待機時だけ更新ボタンを表示。ボタン操作後、盤面を保持して更新する。
4. 落ち着いてのんびり遊べる雰囲気。時間制限や失敗による終了は加えず、BGMも穏やかな曲調にする。

## 採用した実装

- Web Workerによる端末生成。オフラインの新規開始を保証するため、GAS問題配信を開始の必須条件にしない。
- 全難易度で20/24/28/32角。サイズはシードだけから選び、難易度から切り離す。初期候補数、解法途中の候補数、相対的な依存深さを同じサイズで比較する。体感難易度・スマホ実負荷は今後調整。
- 生成器4.1.0は連結2×2タイルのサイクル結合で形状内のHamiltonian経路を作り、backbite変形と切り分けで矢印を互いに入り込ませる。mask占有率100%、長さ2〜30、片端先端、既存の採用品質条件を維持し、DAGと独立した直接貪欲法で全消去を検証。形状選択はサイズ・難易度と別のシード系列で決め、ホームで明示選択も可能。形の空白を越えた同一直線上の矢印も妨害する。生成方式・数値条件はGENERATOR.mdに記載。旧版の保存セルとfingerprintは再生成せず、そのまま再開する。
- 指先・マウスの移動8 CSS pxをタップとの境界にする。ピンチ後の指離しをタップへ戻さない。0.2.1からは線との距離でなく、各セルの正方形全体を選択範囲にする。パン・ズームを逆変換してセルを特定し、境界は右・下のセルに所属させる。消去済みセル、演出中の矢印、盤外・表示領域外は選択しない。
- ページのtouch-actionをmanipulation、盤面枠をnoneにし、盤面SVGだけで非passiveのtouchstart/move/endとdblclickの既定動作をキャンセル。iOSの連続タップ拡大への対策であり、入力の時間制限や間引きは行わない。操作は既存Pointer Eventsに一本化し、ピンチ・ドラッグ・ボタン拡大を維持する。ページ全体の倍率上限は追加しない。リスナーはBoardView破棄時に解除する。
- 450msの長押しで先端から外枠までの細い点線を表示する。ガイドは妨害状態によって色や長さを変えず、穴も跨ぐ。表示後の指離しではタップを送らない。ドラッグ8px以上、ピンチ、ホイール、ズーム、キャンセル、非表示・フォーカス喪失、対象除去、盤面変更、破棄で解除。保存による同一盤面再描画では有効な操作を維持する。
- 消去済みセルの中心に薄いドットを描き、再開・パン・ズーム・明暗切替に対応。PCカーソルは線上/セル角/ドラッグ中を人差し指で統一。
- ヒントは3回。同じ残存状態の再表示は無料。除去後は強調解除。
- ミス数はshowMistakesでプレイ中・クリア時の表示を切り替え、既定は非表示。成績画面から累計ミス・ノーミス率・ノーミスクリアを除外し、その説明も表示しない。既存の保存・同期形式は保持する。ミスの内部記録は破棄プレイも含める。ヒント使用とノーミスは別。クリア記録はfingerprint、ミス集計元はplayIdで重複排除。
- 設定は項目別の変更時刻とdeviceIdで決定的に統合。端末時計の差を解消するサーバー時刻同期は未実装。
- 5曲のオリジナル合成BGM・効果音を使用。56〜76 BPM、正弦波中心で打楽器を使わず、休符や穏やかな和音で曲ごとに変化をつける。playIdから選曲し、同じ盤面の再描画・設定変更でフレーズをリセットしない。再開時も同じ曲。曲停止・切替は短くフェードし、BGMと効果音の音声経路を分離する。効果音は再生中の和音の構成音を使い、BGMを停止しても選択曲に合う音を出す。通常除去4声・効果音全体8声を上限としBGMは止めない。音源の録音・通信は追加しない。実機での音量・再生制限・聴感の確認は別途必要。
- 経路の角を0.25セルの二次曲線で丸め、移動中の短い線分では半長以内へ縮める。先端とセルのタップ範囲は維持。
- 矢印色はグリーン・ブルー・パープル・テラコッタ。項目別時刻付きarrowThemeとして保存・同期。表示モードはライト・ダーク・端末連動のcolorMode。showMistakesを含む8項目を保存・同期し、旧5/6/7項目設定は盤面とrevisionを保持して不足分だけ既定値を補完。ミス表示はfalse。
- 除去を保存した後は演出終了を待たず次の操作を受け付ける。保存処理中の入力も所有者・プレイID・世代付きのFIFOで順に処理する。複数の移動を並行描画し、最後の除去だけ全演出完了を待ってクリア画面へ戻す。

## 検証基準

- 構造、先端レイ、自己干渉、単調性、経路追従、シード再現、ID非依存fingerprint。
- 4難易度×4サイズ×100シードを別実装の除去判定でも全消去。
- 6形状×4サイズ×4難易度×25シードのmask完全被覆・空白不使用・独立した2合法順での全消去、形状内の難易度差、旧v1/v2/v3/v4保存互換。
- 音声の決定的選曲、同じ盤面での継続、BGM/SFX分離、非表示復帰、長時間ノード解放、Web Audio実スケジュール。
- IndexedDB: 盤面・統計の原子的保存、revision比較、破損時の元データ保持、UID分離。
- ブラウザー: ミス1回、ドラッグ無操作、ヒント再表示、再読込再開、新規置換、全消去と二重計上防止。
- モバイル幅354/390px、オフラインのアプリ起動とWorker生成、旧タブ拒否、更新ボタンとセーブ保持。
- クラウド: ルールとSDKのローカルエミュレータ検証。実Google認証・実Firestore同期・実GASとは区別。

## 外部接続

専用FirebaseをSparkプランで作成し、Google認証、公開ドメイン、東京のFirestoreと本人UID・公開フィールド限定のルールを設定。GASの匿名health/meta/difficultiesと実Sheet読取は成功。ゲーム開始はGASに依存しない。Pages公開後のブラウザー・認証・同期の実証はINTEGRATION.mdで区別して記録する。スマートフォン実機は別途確認する。

更新時は旧タブが使うハッシュ付き資産を旧キャッシュから取得できる。現在のbundleが動作することを全タブから確認してから旧キャッシュを削除し、更新操作のないタブを強制再読込しない。資産URLが変わる2版・2タブでオフライン生成とキャッシュ整理を試験する。

## 視覚検証

初期Image Gen案の書籍風の配色と大見出しは、ユーザーの訂正により数独型へ変更。最終比較対象は参照専用で読んだ数独の `homeView` とスタイル、およびユーザーの密な矢印盤面画像。

ホームの見出し・難易度行・続きボタン・下部メニュー、青緑と紙色、文字サイズ、間隔、スマホの横はみ出し、片端先端・格子占有を画面で比較する。初期案への忠実再現を完了条件にはしない。
