# 実装判断と受入条件

2026-10-20 / 0.1.0

元仕様の「文書作成のみ」は過去の作業範囲。今回はゲームの作成依頼として実装。管理URLを含む元仕様書は公開ツリーに複製しない。

## 現在のUI要件

ユーザーの最新訂正を優先する。

1. 均等な格子を隙間なく埋める。矢印の先端は片端に1つだけ。
2. 数独のホーム構成を参照。難易度行で新規開始、「つづきから」、設定・成績・遊び方。キャッチコピーや情緒的な文言は不要。
3. Service Worker更新待機時だけ更新ボタンを表示。ボタン操作後、盤面を保持して更新する。

## 採用した初期案

- Web Workerによる端末生成。オフラインの新規開始を保証するため、GAS問題配信を開始の必須条件にしない。
- 20/24/28/32角。長さ・曲がりが難易度ごとに増える。人間の体感難易度・スマホ実負荷は今後調整。
- 盤面を面積2〜30の長方形に区切って蛇行経路にする。先端を適切な外周方向へ向け、DAGと独立した直接貪欲法でも検証。占有率100%。形状はこの生成版の特徴で、唯一解を要求しない。
- 指先・マウスの移動8 CSS pxをタップとの境界にする。ピンチ後の指離しをタップへ戻さない。曖昧な対象は無操作。
- ヒントは3回。同じ残存状態の再表示は無料。除去後は強調解除。
- ミスは破棄プレイも累計に含める。ヒント使用とノーミスは別。クリア記録はfingerprint、ミス集計元はplayIdで重複排除。
- 設定は項目別の変更時刻とdeviceIdで決定的に統合。端末時計の差を解消するサーバー時刻同期は未実装。
- 合成BGM・効果音を使用。録音や他アプリの音源を転用しない。実機での音量・再生制限の確認は別途必要。

## 検証基準

- 構造、先端レイ、自己干渉、単調性、経路追従、シード再現、ID非依存fingerprint。
- 4難易度×100シードを別実装の除去判定でも全消去。
- IndexedDB: 盤面・統計の原子的保存、revision比較、破損時の元データ保持、UID分離。
- ブラウザー: ミス1回、ドラッグ無操作、ヒント再表示、再読込再開、新規置換、全消去と二重計上防止。
- モバイル幅354/390px、オフラインのアプリ起動とWorker生成、旧タブ拒否、更新ボタンとセーブ保持。
- クラウド: ルールとSDKのローカルエミュレータ検証。実Google認証・実Firestore同期・実GASとは区別。

## 未接続

Firebase専用環境・実Googleログイン・実複数端末同期、指定GAS/Sheetsの実接続、Pages新規公開は未完了。外部接続が未設定でも端末内で遊べる。

## 視覚検証

初期Image Gen案の書籍風の配色と大見出しは、ユーザーの訂正により数独型へ変更。最終比較対象は参照専用で読んだ数独の `homeView` とスタイル、およびユーザーの密な矢印盤面画像。

ホームの見出し・難易度行・続きボタン・下部メニュー、青緑と紙色、文字サイズ、間隔、スマホの横はみ出し、片端先端・格子占有を画面で比較する。初期案への忠実再現を完了条件にはしない。
