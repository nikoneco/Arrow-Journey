# 盤面生成器 5.0.0

## 0.6.0の調整方針（2026-10-27）

長い矢印をたどって抜く楽しさを保ち、短い矢印への置換で難しくしない。旧版の長さ帯と重みは全難易度で維持する。生成器版は `5.0.0`、難易度プロファイル版は `4.0.0`、ルール版は `1.0.0`。

- 通常のランダムサイズは全難易度で **28 / 32 / 36 / 40**。サイズ・形状・難易度は引き続き別々の選択で、同じシードなら難易度を変えてもサイズ・形状は一致する。
- ランダム形状は正方形80%、円・ひし形・十字・ハート・ドーナツ各4%。手動選択した形状はそのまま使う。外周が多い形状ばかりになって難しさが下がることを避けつつ、形の変化を残す。
- `generateBoard(..., { size })` は旧20 / 24も受理する。保存済みの20〜32角を作り直すことはなく、構造検証の上限64も変更しない。
- Expertでは切り出し候補の前後に残るHamiltonian経路の区間が2〜5セルになる場合、1区間につきスコアを8下げる。長い矢印を切り分けるのではなく、後で短い端切れになる切り方を避ける。長さ2と30を含む条件、長さ帯、深さ優先度は維持する。他の難易度は従来の切り出しスコアを使う。
- 初期消去候補数、依存深さ比、非長方形経路、相互に入り込む経路の旧品質条件を維持する。形状による品質緩和はしない。
- Expertは従来のFIFO合法順に加え、下記の解放優先順で1手の新規解放が最大4本になることも採用判定に使う。平均候補数のハード上限は、大きな正方形で生成失敗が出たため設けず、回帰比較で測定する。再生成上限を32回とし、失敗時は例外を返す。品質条件を緩めた代替盤面は返さない。

6形状のmask内100%占有、2〜30セル、片端の先端、尾→先端のセル列、穴を越えるレイ、独立した直接走査解法とDAGの両方による全消去は変更しない。

## 解放の集中を調べる合法順

`solveBoard` の既存の `choicesOverTime` / `meanChoices` はFIFO順の指標であり、そのまま維持する。追加の `greedyPolicy: 'max-immediate-unlocks-longest-first'` は次の決定的な順序を表す。

1. 現在合法な各矢印について、その1本を抜いた直後に新たに合法になる矢印数を数える。
2. 新しい解放数が最多の矢印を選ぶ。同数なら長い矢印、それでも同じなら候補キューの順を使う。
3. その矢印を除去し、残りがなくなるまで繰り返す。

`greedyChoicesOverTime` / `greedyUnlocksOverTime` に各手の候補数と新しい解放数を記録し、`greedyMeanChoices`、`greedyMaxUnlocks`、5本以上選べる手の割合 `greedyLargeChoiceRatio`、最初の80%の平均 `greedyEarlyMeanChoices`、最後の四分の一の平均 `greedyFinalQuarterMeanChoices`、末尾がすべて合法になる区間の比率 `greedyTerminalFreeRatio` を返す。

この順序は解放が集中する盤面を探すための具体的なプレイ方針であり、すべての合法順の最大値・平均値や人間のクリア時間ではない。採用条件もこの順序での上限であり、任意のプレイ順への保証ではない。

## 形状・サイズと保存形式

`BOARD_SHAPES` は凍結された `{ id, label }` の配列。IDと表示名は `square` / 正方形、`circle` / 円、`diamond` / ひし形、`cross` / 十字、`heart` / ハート、`ring` / ドーナツ。

全形状・全難易度が20×20、24×24、28×28、32×32の外枠に対応する。サイズと形状を別々のシード専用乱数列で選び、難易度を参照しない。同じシードならEasy〜Expertの形状・サイズが一致する。サイズを指定しても形状の選択は変わらず、形状を指定してもサイズの選択は変わらない。

`generateBoard(difficulty, seed, { size, shape })` で対応するサイズ・形状を指定できる。省略時に選ばれた値を明示しても、同じシードと難易度ならセル列、ID、生成作業量まで一致する。未対応サイズ・形状は例外にする。

新盤面には `board.shape` と `board.mask` を保存する。maskはプレイ可能な全セルを表す `[x, y]` 配列であり、残存セルだけに縮めない。すべての形状は連結した2×2タイルの集合で、矢印はmaskを過不足なく占有する。外枠内のmask外セルは空白とする。マスクの不正座標・範囲外・重複、空白への矢印配置、被覆不足を構造検証で拒否する。

ドーナツは円と同じ外周から、半径40%の中央円に含まれる2×2タイルを除いた形状。タイル中心で内外を判定するため、中央には外部の空白とつながらない1つの穴があり、周囲のプレイ領域は連結したまま。20 / 24 / 28 / 32サイズの穴面積は48 / 64 / 96 / 128セル。穴にも矢印やドットを置かず、maskのセルだけを描画する。

`mask` のない保存盤面には従来どおり長方形内の座標検証を適用し、疎な旧盤面も再生成せず扱う。`DIFFICULTIES.*.sizes` は凍結された `[20, 24, 28, 32]`、`width` / `height` は旧公開メタデータとの互換用代表値のまま。表示・保存には実際の `board.width` / `board.height` を使う。GASの難易度メタデータ変更は不要。

**先端レイはmaskの空白でも止まらない。** 外枠まで走査し、空白の向こう側にある別の張り出し部分や、ドーナツの穴の反対側の矢印も妨害として扱う。ルールと衝突判定は従来どおり。

## 難易度

難易度の中心は消去候補の**絶対数**と依存関係。サイズ・形状は難易度と独立して選び、大きい盤面で候補の割合だけが下がることを難しさとして扱わない。採用条件は次のとおり。

| 指標 | Easy | Normal | Hard | Expert |
| --- | ---: | ---: | ---: | ---: |
| 初期消去可能数 | 8〜14 | 5〜8 | 3〜5 | 1〜3 |
| 依存深さ÷矢印総数の下限 | 10% | 20% | 28% | 40% |
| 非長方形経路の割合の下限 | 55% | 60% | 60% | 60% |
| 相互に入り込む外接矩形を持つ経路の割合の下限 | 30% | 45% | 50% | 50% |

依存深さの実際の下限は `ceil(minDepthRatio * arrowCount)`。初期候補数の目標は11 / 7 / 4 / 2本。上位難易度では既に切り出した深い依存経路の先につながる切り方を強く優先し、途中の選択肢も少なくする。形状によって採用条件を緩める処理はない。

「非長方形」は外接矩形面積が経路セル数より大きいこと。「相互に入り込む」は、経路AのセルがBの外接矩形内にあり、同時にBのセルがAの外接矩形内にあること。単なる外接矩形の重なり数も別途記録する。「隣接相手数」は経路の各セルの上下左右に接する、異なる矢印の種類数。

`solveBoard().metrics.density` は占有セル数÷maskのセル数で、新盤面は常に1。`playableCells` に分母を記録し、外枠面積に対する占有率は `boundingBoxDensity` として区別する。maskのない旧盤面では従来の幅×高さを分母にする。

これらは形状、候補探索、依存の深さを表す指標であり、人間の体感難易度を実測した値ではない。合法な除去によって新しい妨害は生まれないため、合法な選択を理由に手詰まりになることはない。

## 生成方法と上限

1. 形状ごとに2×2タイルの連結マスクを作る。各タイル内に4セルのサイクルを置く。
2. タイルの隣接グラフ上でランダムな深さ優先の全域木を作る。木の辺ごとに、隣り合う2タイルの共有境界に平行な2本の辺を外し、境界を横切る2本の辺につなぎ替える。別サイクル同士を結合するので、最後にはmaskの全セルを1回ずつ通る1本のサイクルになる。
3. サイクルの開始点・向きを選んで1本のHamiltonian経路にする。backbite操作をプレイ面積×8 / 12 / 16 / 20回試す。mask内の隣接セルだけを使う区間反転なので、全セル被覆、連続性、重複のない経路が保たれる。タイル境界を切り出し区画として使わない。
4. 外枠の各辺から空白を通過して走査し、残存セルのうち先端レイが空になるセルを探す。そこを先端にできる元経路の2〜30セルを切り出す。残る経路区間が1セルだけになる切り方は使わない。
5. 切り出した経路を除去済みとして続ける。先端レイには既に切り出した経路しか存在しないため、切り出し順に全消去できる。自己干渉も生じない。
6. IDと列挙順を振り直し、生成時の解答順を隠す。構造検証、依存DAG、セルを直接走査する別の貪欲法、難易度・形状条件をすべて通った盤面だけを返す。

すべての新盤面でmask占有率100%、長さ2の矢印と長さ30の矢印を含む。各候補の切り出しは最大mask面積÷2回、各回の候補検査は最大 `2*(width+height)*29`。再生成は最大16盤面で終了し、失敗時は例外を返す。品質を下げる代替盤面、疎な盤面、別難易度への切替は行わない。旧セーブを保持する判断は呼出側の責務。時刻、DOM、ストレージ、ネットワークは参照しない。
