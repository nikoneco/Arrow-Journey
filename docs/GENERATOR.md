# 盤面生成器 3.0.0

格子を100%占有する2〜30セルの経路を、長方形の区画に閉じ込めずに生成する。セル列は尾→先端で、先端は片端に1つ。ルール版は `1.0.0`、生成器版と難易度プロファイル版は `3.0.0`。

## サイズと難易度

全難易度が20×20、24×24、28×28、32×32に対応する。サイズはシード専用の乱数列で選び、難易度を参照しない。同じシードならEasy〜Expertで同じサイズとなり、同じ難易度にも小さい盤面と大きい盤面が現れる。

`DIFFICULTIES.*.sizes` は凍結された `[20, 24, 28, 32]`。`width` / `height` は旧公開メタデータとの互換用の代表値として残している。実際の表示と保存には生成された `board.width` / `board.height` を使う。

`generateBoard(difficulty, seed, { size })` で対応するサイズを指定できる。省略時に選ばれたサイズを明示しても、同じシードと難易度ならセル列、ID、生成作業量まで一致する。未対応サイズは例外にする。

難易度の中心は消去候補の**絶対数**と依存関係。大きい盤面で候補の割合だけが下がることを難しさとして扱わない。採用条件は次のとおり。

| 指標 | Easy | Normal | Hard | Expert |
| --- | ---: | ---: | ---: | ---: |
| 初期消去可能数 | 8〜14 | 5〜8 | 3〜5 | 1〜3 |
| 依存深さ÷矢印総数の下限 | 10% | 20% | 28% | 40% |
| 非長方形経路の割合の下限 | 55% | 60% | 60% | 60% |
| 相互に入り込む外接矩形を持つ経路の割合の下限 | 30% | 45% | 50% | 50% |

依存深さは整数なので、実際の下限は `ceil(minDepthRatio * arrowCount)`。初期候補数の目標は11 / 7 / 4 / 2本。上位難易度では既に切り出した深い依存経路の先につながる切り方を強く優先し、途中の選択肢も少なくする。

「非長方形」は外接矩形面積が経路セル数より大きいこと。「相互に入り込む」は、経路AのセルがBの外接矩形内にあり、同時にBのセルがAの外接矩形内にあること。単なる外接矩形の重なり数も別途記録する。「隣接相手数」は経路の各セルの上下左右に接する、異なる矢印の種類数。

これらは形状、候補探索、依存の深さを表す指標であり、人間の体感難易度を実測した値ではない。このゲームでは合法な除去によって新しい妨害は生まれないため、合法な選択を理由に手詰まりになることはない。

## 生成方法と上限

1. 格子の全セルを1回ずつ通るHamiltonian経路を作る。
2. 経路の片端と隣接セルを接続し直すbackbite操作を、面積×8 / 12 / 16 / 20回試す。途中区間の反転なので、全セルの被覆、連続性、重複のない1本の経路が保たれる。区画や帯の境界は残さない。
3. 盤面の各辺から走査し、残存セルのうち先端レイが空になるセルを探す。そこを先端にできる元経路の2〜30セルを切り出す。残る経路区間が1セルだけになる切り方は使わない。
4. 切り出した経路を除去済みとして続ける。先端レイには既に切り出した経路しか存在しないため、切り出し順に全消去できる。自己干渉も生じない。
5. IDと列挙順を振り直し、生成時の解答順を隠す。構造検証、依存DAG、セルを直接走査する別の貪欲法、難易度・形状条件をすべて通った盤面だけを返す。

すべての盤面で占有率100%、長さ2の矢印と長さ30の矢印を含む。各候補の切り出しは最大面積÷2回、各回の候補検査は最大 `2*(width+height)*29`。再生成は最大16盤面で終了し、失敗時は例外を返す。品質を下げる代替盤面、疎な盤面、別難易度への切替は行わない。旧セーブを保持する判断は呼出側の責務。時刻、DOM、ストレージ、ネットワークは参照しない。

途中の候補数は、DAGソルバーの決定的な合法順に沿った観測。すべての合法順の平均ではない。同じサイズ内で隣接難易度を比較すると、初期候補数は1.5本超、平均候補数は0.4本超減り、依存深さ比は6ポイント超増えることを試験で確認する。依存辺数は形状の記録用に残すが、難易度の単調増加条件にはしない。

`node --test tests/engine.test.js` の15テストが成功。1,600盤面について、構造、100%の全セル被覆、長さ、品質条件、全消去、テスト側の別実装による阻害判定、異なる合法順での全消去を確認した。24シード×4難易度でサイズの一致と全サイズへの分布を確認し、各組の代表シードおよび4回以上再生成した盤面で正確な再現性も確認している。衝突、自己干渉、循環、折れ線追従、fingerprintの既存試験も維持する。

正式試験の最大生成時間は76.3ms、最大試行回数は7、試験全体は41.9秒。このPCのNodeによる値であり、スマホ実機の負荷を保証する値ではない。

## 再現・保存互換

同じシード、サイズ、難易度、生成器版、プロファイル版、ルール版から同じ盤面になる。fingerprintは引き続き `aj1-` 形式で、幅・高さ・尾→先端のセル列から計算し、列挙順・ID・メタデータに依存しない。

保存済みのセル列が再開時の正本。旧生成器の保存盤面に新版の生成・品質条件は課さず、作り直さない。ルールと衝突判定は変更していない。1.0.0の盤面に加え、2.0.0の実生成経路を固定した回帰試験で、セル列を変更せず検証・全消去でき、旧fingerprint `aj1-cefaf2d525077d9f3efd55c5d500da8f` が維持されることを確認する。

`visual-review` シードのブラウザー比較用fingerprint。全難易度で20×20になる。

- Easy: `aj1-aaa56a572727dec3c1040bd54c86bf41`
- Normal: `aj1-bb93d2a9be8051986cbf114769ac9276`
- Hard: `aj1-64f76b8c2ab6cf151af4c2ea54b56673`
- Expert: `aj1-a5e212608c8a51278186c33ca8ee807b`

ブラウザー描画、スマホ実機操作、体感難易度、公開先への反映は、このエンジン単体の自動試験とは別に確認する。
